# Research Problem

How can a small language model be designed, implemented, trained, and
evaluated from first principles using limited computational resources?

## Main Questions

1. How does a language model learn statistical patterns in text?
2. How does tokenization affect model behavior?
3. How do embeddings represent tokens?
4. Why does self-attention work?
5. How does a Transformer learn next-token prediction?
6. How do model size and dataset size affect performance?
7. How can small language models be made more computationally efficient?
